# Brein-setup

Installatiescript voor het tweede brein op een Windows-laptop.

Open Windows PowerShell en plak deze ene regel:

```
irm https://raw.githubusercontent.com/plaatsr-group/brein-setup/main/zet-mijn-brein-op.ps1 | iex
```

Het script installeert Git, Obsidian en Claude, haalt het brein op van GitHub en opent het in Obsidian.
